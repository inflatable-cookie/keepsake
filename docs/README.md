# Keepsake — current state

Keepsake is a CLAP plugin that bridges legacy plugins — VST2, VST3, AU v2,
including 32-bit binaries — through isolated helper processes. `v0.1-alpha` is
published; macOS + REAPER + VST2 is the strongest proven lane, and Windows,
Linux, VST3, AU v2 and 32-bit stay experimental until the validation matrix
defends wider claims.
