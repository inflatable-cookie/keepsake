# G01 — Initial Build and Proof-of-Concept (Archived)

Status: archived

Succeeding generation: `g02` (see `../g02/README.md`)

## Generation intent and boundary

G01 took Keepsake from zero to a playable, automatable, saveable,
multi-format plugin bridge with GUIs in a CLAP host. The closing bar was
bridged plugins fully playable across macOS, Windows, and Linux for VST2,
VST3, and AU v2 including 32-bit plugins. All sixteen executed tasks
closed `complete`; the Soundcheck HTTP-API plan closed `superseded`; the
IOSurface embedded-editor card closed `parked` as research evidence.

This roll-up replaces the expanded `g01/` tree (sixteen task files plus
the generation README). The per-task files are gone; git history retains
the full-fidelity record.

## Shipped outcomes by durable capability

- **CLAP factory and loaders** (`001`, `008`) — CMake build, CLAP entry
  point and factory, VeSTige VST2 loader with architecture detection,
  bridge loader abstraction, AU v2 scanning and loading.
  Canonical home: `docs/contracts/002-clap-factory-interface.md`.
- **Audio bridge and subprocess isolation** (`002`, `010`) — bridge
  subprocess binary, pipe protocol, shared-memory audio, full CLAP plugin
  lifecycle, configurable shared/per-binary/per-instance isolation.
  Canonical homes: `docs/contracts/004-ipc-bridge-protocol.md`,
  `docs/contracts/006-process-isolation-policy.md`.
- **MIDI, parameters, state** (`005`) — note events, parameter
  automation, state save/restore through the bridge.
  Canonical home: `docs/contracts/004-ipc-bridge-protocol.md`.
- **Scan, cache, configuration** (`004`, `014`) — scan caching,
  `config.toml`, rescan sentinel, crash-history reporting.
- **Cross-platform and cross-architecture** (`003`, `009`) — platform
  abstraction layer, macOS/Windows/Linux backends, x86_64 bridge under
  Rosetta, packed IPC structs, PE/ELF detection, 32-bit bridge routing.
- **Editors and GUI** (`006`, `011`, `012`, `013`) — floating-window GUI,
  macOS Cocoa editor hosting, CLAP GUI extension, editor header bar,
  Windows/Linux GUI, embedded-editor attempts.
  Live macOS posture now owned by
  `docs/contracts/007-macos-native-editor-and-host-placeholder.md` and
  `docs/architecture/macos-bridged-ui-options.md`.
- **CI and codebase health** (`007`, `015`) — cross-platform testing
  lane and health follow-through. Accepted residual debt (god-file scan
  warnings, TODO markers) is tracked by `effigy doctor`, not by this
  roll-up.

## Current canonical destinations for lasting decisions

- VeSTige-only loading, CLAP-outer-format, subprocess-only VST3 SDK:
  `docs/contracts/001-working-rules.md` (legal guardrails).
- Factory, IPC, isolation semantics: contracts `002`, `004`, `006`.
- No Soundcheck runtime/API dependency of any kind: the contract index
  external-contracts section and contract `006` managed-settings source.
- macOS primary path is the bridge-owned live editor; embedded preview
  is diagnostic-only: contract `007`, `macos-bridged-ui-options.md`,
  `docs/known-issues-v0.1-alpha.md`.

## Migrations, compatibility limits, retained risks

- 32-bit bridging stays first-class per platform limits in
  `docs/project-brief.md`; broader platform/format support remains
  experimental until matrix evidence moves the envelope.
- Known VeSTige-license and VST3-SDK-integration risks raised during g01
  remain bounded by the legal guardrails in `001-working-rules.md`.
